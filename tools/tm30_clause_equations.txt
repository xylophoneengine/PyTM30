# TM-30-20 clause -> printed-equation map, used by check_constants.py to
# validate `TM-30-20 §x.y ... Eq. (nn)` citation tags in src/ and include/.
#
# Document identity (the exact edition these equation numbers refer to):
#   ANSI/IES TM-30-20, "IES Method for Evaluating Light Source Color
#   Rendition", An American National Standard, incorporating Errata 1
#   (errata list last updated May 7, 2021).
#   Copyright 2018 by the Illuminating Engineering Society; approved as
#   an American National Standard July 27, 2018; Annexes E and F
#   approved September 23, 2019.
#   ISBN 978-0-87995-379-9.
#
# The equation numbers in this map are specific to THIS edition.
# Equation numbering can drift between revisions: any other edition or
# revision must be re-verified clause by clause before editing this map.
#
# Format, one clause per line:
#   <clause>: <first>-<last>              equations printed in that clause
#   <clause>: <n>                         single equation
#   <clause>: none                        clause prints no numbered equations
# A trailing '# ...' comment on an entry line is ignored by the parser;
# it carries the clause title for human lookup.
# Append 'unverified' to any entry not yet confirmed against a licensed
# copy of ANSI/IES TM-30-20. Unverified entries produce warnings, not
# failures.
#

# 2026-08-14: every equation number below matches the printed clause.
